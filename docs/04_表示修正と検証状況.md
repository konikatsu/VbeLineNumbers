# 表示修正と検証状況（2026-10-06）

## 修正内容

提供された画像では、行番号欄がプロジェクト一覧へ重なり、番号の表示範囲がコード欄の下端まで届いていませんでした。

- 固定のヘッダー高さを廃止し、アクティブな `VbaWindow` のクライアント座標と縦スクロールバーからコード表示範囲を取得します。
- ネイティブのカーソルの高さと位置から、行の高さと先頭行の位置を合わせます。カーソル情報がない場合はフォントと表示行数から計算し、直前の計測結果を保持します。
- 番号を描く行数は、実際の表示範囲の高さと行の高さから決めます。モジュールの末尾より先の番号は描きません。
- VBE内部に番号欄の幅を確保します。アドイン終了時に元の配置へ戻します。幅を確保できない場合は番号欄を隠します。
- フォントを対象ウィンドウのDPIに合わせたピクセル単位にし、WinFormsの自動サイズ変更を無効にします。
- VBE非表示、別アプリの操作中、コードウィンドウ以外の表示時は番号欄を隠します。
- COMのGUIDとProgIdは維持しています。VBAコード本文は変更しません。

## ビルド

このPCにはMSBuildのCOM参照解決に必要なWindows SDKツールがないため、Microsoft.Net.Compilers.Toolset 4.8.0のC#コンパイラー、Microsoft.NETFramework.ReferenceAssemblies.net48 1.0.3の参照アセンブリ、インストール済みOfficeの相互運用アセンブリでビルドします。

```powershell
.\scripts\Build-Local.ps1
```

このスクリプトはコンパイラーをインストール・ダウンロードしません。既定では `.tools\compiler\tasks\net472\csc.exe` と `.tools\net48\build\.NETFramework\v4.8` を使用します。必要に応じて `-CompilerPath`、`-FrameworkReferencePath`、`-VbeInteropPath`、`-ExtensibilityPath` を指定します。

Visual StudioとWindows SDKを備えた環境では、従来どおり `VbeLineNumbers.csproj` をMSBuildでビルドできます。
